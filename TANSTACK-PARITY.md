# TanStack Table parity checklist

Every feature of [TanStack Table](https://tanstack.com/table) (v9 docs,
fetched 2026-11-05 from the docs index at
`TanStack/table` `docs/config.json`), each with its docs page, mapped to
vuistack-table. Status is one of:

- **have**: vuistack-table does it; the last column says how.
- **missing**: not done yet.
- **not applicable**: the feature only exists for a browser/JS concern
  Emacs doesn't have; the last column says why.

`test/vuistack-table-parity-test.el` fails if a row says `missing` or has
no docs link. Keys are those of `vuistack-table-mode`. Commands act on
the table at point.

Docs base: `https://tanstack.com/table/latest/docs/`.

## Core guides

| Feature | TanStack source | Status | vuistack-table |
| --- | --- | --- | --- |
| Headless core, opt-in features | [overview](https://tanstack.com/table/latest/docs/overview), [features](https://tanstack.com/table/latest/docs/guide/features) | have | `vuistack-table-row-model` and `vuistack-table--display-columns` are the pure, render-free core; features turn on with props (`:page-size`, `:enable-row-selection`, ...). |
| Tree-shaken feature registration (`tableFeatures`) | [features](https://tanstack.com/table/latest/docs/guide/features) | not applicable | This is about JS bundle size. An Emacs package loads as a whole, and a feature you never turn on costs nothing. |
| Data: rows of any shape | [data](https://tanstack.com/table/latest/docs/guide/data) | have | `:rows` is a list of plists. `:get` reads any shape. |
| Deep keyed data / array indices | [column defs](https://tanstack.com/table/latest/docs/guide/column-defs) | have | Column `:path`, e.g. `(:address :city)` or `(:tags 0)`, walks plists, lists, vectors and alists. |
| Nested sub-row data (`getSubRows`) | [data](https://tanstack.com/table/latest/docs/guide/data), [rows](https://tanstack.com/table/latest/docs/guide/rows) | have | A row's `:sub-rows`, or the `:get-sub-rows` prop `(ROW -> rows)`. |
| TypeScript generics, type helpers | [helpers](https://tanstack.com/table/latest/docs/guide/helpers) | not applicable | Emacs Lisp has no static types. |
| Client-side vs server-side (manual) processing | [client-side vs server-side](https://tanstack.com/table/latest/docs/guide/client-side-vs-server-side) | have | `:manual-filtering`, `:manual-sorting`, `:manual-grouping`, `:manual-pagination` (with `:row-count` / `:page-count`) and `:manual-expanding` keep the state and the UI but leave the rows as given. `:on-state-change` tells the server what changed. |
| Column definitions: accessor, display and group columns | [column defs](https://tanstack.com/table/latest/docs/guide/column-defs) | have | Accessor: `:key` / `:get` / `:path`. Display: `:cell` with no key. Group: a spec with `:columns`. |
| Unique column ids | [column defs](https://tanstack.com/table/latest/docs/guide/column-defs) | have | `:id`, else `:key`, else `:header`. State and `:initial-state` accept any of them (`vuistack-table--resolve-column`). |
| Cell, aggregated-cell, header and footer formatting | [column defs](https://tanstack.com/table/latest/docs/guide/column-defs) | have | `:format`, `:cell`, `:money`, `:aggregated-format`, `:header`, `:footer`. |
| Table instance, table state | [tables](https://tanstack.com/table/latest/docs/guide/tables) | have | `vuistack-table-state`, `vuistack-table-set-state`, one plist per table ID. |
| Initial state | [tables](https://tanstack.com/table/latest/docs/guide/tables) | have | `:initial-state` (`:sort :filter :column-filters :hidden :order :pin-left :pin-right :widths :grouping :expanded :selected :pin-top :pin-bottom :page :page-size`), seeded on the first render. Column `:hidden t` starts a column hidden. |
| Controlled state, `onStateChange` | [tables](https://tanstack.com/table/latest/docs/guide/tables) | have | `:on-state-change (ID STATE)` runs after every change; `vuistack-table-set-state` drives the table from outside. |
| Reset state | [tables](https://tanstack.com/table/latest/docs/guide/tables) | have | `C-c C-r` `vuistack-table-reset-table` goes back to `:initial-state`. |
| Row models pipeline | [row models](https://tanstack.com/table/latest/docs/guide/row-models) | have | `vuistack-table-row-model` runs core, filtered, grouped, sorted, expanded, paginated, plus the pinned rows. |
| Worker row models (experimental) | [worker row models](https://tanstack.com/table/latest/docs/guide/worker-row-models) | not applicable | Web Workers move work off the browser's UI thread. Emacs has no such workers, and its row model runs while it renders. |
| Rows: ids, original data, values | [rows](https://tanstack.com/table/latest/docs/guide/rows) | have | `:row-id (ROW -> id)`, else the index path `"0.1"`. `vuistack-table-get-row`, `vuistack-table-row-at-point`, the `vuistack-table-row` / `vuistack-table-node` text properties. |
| Row numbers / display indexes | [rows](https://tanstack.com/table/latest/docs/guide/rows) | have | A column with `:row-number t` shows the row's 1-based display index, counted across pages. |
| Cells | [cells](https://tanstack.com/table/latest/docs/guide/cells) | have | `vuistack-table--cell-value`, `:cell (ROW WIDTH)` renderers, multi-line cells. |
| Header groups (nested headers) | [header groups](https://tanstack.com/table/latest/docs/guide/header-groups), [headers](https://tanstack.com/table/latest/docs/guide/headers) | have | Group column specs render one heading line per level. Each group spans its adjacent visible leaves and is widened to fit, with placeholders where a leaf has no group. |
| Columns API | [columns](https://tanstack.com/table/latest/docs/guide/columns) | have | Leaf columns (`vuistack-table--leaf-columns`), visible columns in display order (`vuistack-table--display-columns`). |
| Table and column meta | [table and column meta](https://tanstack.com/table/latest/docs/guide/table-and-column-meta) | have | Column and row plists are open: any extra key (`:meta`, ...) reaches every callback. The meta guide's editable-cell case is column `:on-edit (ROW TEXT)`, run by `E` `vuistack-table-edit-cell`. |
| Devtools | [devtools](https://tanstack.com/table/latest/docs/devtools) | have | `C-c C-d` `vuistack-table-describe` shows the table's state and row counts. |
| Framework adapters (React, Vue, Solid, ...) | [overview](https://tanstack.com/table/latest/docs/overview) | not applicable | vui.el is the only framework here. |
